# Polished Corpus Editor on Milkdown

## Context

The docs editor (`src/components/docs-editor/`, Milkdown 7.22.3 built from separate packages per `docs/decisions/proposed-docs-editor.md`) is a working prototype: slash menu, `[[` page picker, selection tooltip, sticky toolbar, task lists. It needs Notion/Obsidian/Mintlify-level polish. Confirmed by research: `@milkdown/components` depends on **Vue 3** — so it stays off the table (ADR), and everything remains custom React styled with shadcn/Base UI/Tailwind 4. The vanilla official plugins (`plugin-block`, `plugin-cursor`, `plugin-upload`, `plugin-prism`) are clean MIT packages with no Vue/CodeMirror/KaTeX baggage.

**User decisions:** reicon for editor icons (lucide per-glyph fallback if a glyph truly doesn't exist) · all needed Milkdown plugin deps approved · pasted/dropped images auto-downscale and embed as data URLs until Phase 5 adds real uploads.

## Architecture decisions

- Keep `createDocsEditor()` factory + hand-rolled React wrapper. No `@milkdown/react`, no kit, no Crepe, no `@milkdown/components`.
- New deps, all pinned exact: `@milkdown/plugin-block`, `@milkdown/plugin-cursor`, `@milkdown/plugin-upload`, `@milkdown/plugin-prism` (brings `refractor`) — all `7.22.3` — plus `reicon-react` (`1.2.6`, MIT, zero deps, tree-shakeable, PascalCase imports, `weight="Outline"|"Filled"`).
- New `src/components/docs-editor/icons.tsx`: every icon the editor uses exported from one module (reicon first, lucide fallback per glyph). Single swap point, de-risks reicon name gaps (`Table`, `Quote`, `Grip` 404'd under obvious names; probe `cdn.jsdelivr.net/npm/reicon-react@1.2.6/icons/<Name>.js` with curl to finalize the map).
- Split the growing `docs-editor.tsx` (1034 lines) into focused modules; editor chrome CSS moves to a new `src/components/docs-editor/editor.css` imported there. Reader-shared `.docs-prose` rules stay in `src/index.css`.
- House markdown style untouched — all round-trip fixture tests must stay green.

## Phases (each a small commit)

**0. Deps + icon set.** Install plugins + reicon-react (exact pins). Build `icons.tsx` by probing jsdelivr for exact reicon names (heading/table/quote/grip/rows/columns/image/trash/copy/undo…), falling back to lucide only where reicon truly lacks the glyph.

**1. Block gutter (Notion-style).** Register `plugin-block` + `plugin-cursor`. The block plugin owns hover detection (200ms pointermove, `blockConfig.filterNodes`) and full drag-to-reorder; we supply the handle DOM (React portal into the consumer-provided element — exact hook verified from the package's shipped `src/`, files field includes it). Gutter = grip (drag; click opens Base UI dropdown: Duplicate, Move up/down, Delete via transactions on the provider's `active` node) + plus (reuses existing `addBelow`). Replaces the hand-rolled `onMouseMove` hover-plus in `docs-editor.tsx:735-767`. Style the drop cursor via `dropCursorConfig` with token colors; import gapcursor CSS so clicking beside images/tables works.

**2. Tables.** Verify column resizing is active in the `gfm` array (add `columnResizingPlugin` from `@milkdown/preset-gfm` if not). Floating table toolbar when the selection is inside a table: add/remove row/column, toggle header row, align left/center/right (`setAlignCommand`; `keepTableAlignPlugin` serializes it), delete table. Polish `.selectedCell` styling with tokens.

**3. Code blocks.** `plugin-prism` (refractor) decorations; syntax palette as CSS vars in `editor.css` (neutral, token-driven, dark-aware). Language picker chip when the cursor is in a code block — searchable list of common languages, applies `updateCodeBlockLanguageCommand`; verify fences still round-trip (` ```lang `).

**4. Images.** `plugin-upload` with a custom uploader: canvas downscale (max ~1600px), re-encode, embed as data URL, ~1.5MB cap with a toast on failure (Phase 5 swaps the uploader). Slash "Image" item + toolbar button open `image-form.tsx` (paste URL / choose file) inserting via `insertImageCommand`. Node styling: selected ring, rounded, `max-w-full` in `.docs-prose`.

**5. Slash menu + toolbar polish.** Grouped slash menu (Blocks / Media / Advanced) with two-line Notion-style items (label + description), reicon glyphs, existing fuzzy `ranked()` + ref-based keyboard model preserved. Toolbar gains Image, regrouped clusters, graceful overflow at 390px.

**6. Link card + editorial polish.** Hover card over links in the editor (href, copy, edit via existing `LinkForm`, open external). `::selection` and caret colors from tokens, consistent focus rings, placeholder refresh. Optional: word count / reading time line under the editor in `PageEditor` (`src/pages/handbook.tsx`).

**7. Tests, docs, checks.** Extend `milkdown.test.ts`: round-trips for images, aligned tables, code fences with languages; smoke-mount the new plugins in jsdom (verify refractor behaves; drop prism from the test editor if it fights jsdom). Update the ADR (new plugins, reicon choice, image embedding + Phase 5 swap point) and `PLAN.md`. Run `vp check` + `vp test`.
