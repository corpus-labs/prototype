---
title: Install a theme
description: Get an Acme theme running on Drupal or WordPress.
---

Download the theme from **Account**, then **Downloads**. It comes as a zip file.

## Drupal

Unzip the theme into `themes/custom`, then turn it on under **Appearance**. Acme themes need Drupal 10.3 or newer, and they work on Drupal 11.

## WordPress

Upload the zip under **Appearance**, then **Themes**, then **Add new**. Activate it once the upload finishes.
