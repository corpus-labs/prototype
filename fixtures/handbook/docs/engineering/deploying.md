---
title: Deploying a site
description: From merged pull request to live site.
---

Every campus site deploys from its main branch. Merging a pull request starts the build, and the site goes live when the checks pass.

## Before you merge

- Run the [accessibility review](../quality/accessibility-review.md) on any page you changed.
- Ask for review from someone who didn’t write the change.
- Open the preview link on a phone.

## Rolling out

Deploys go to staging first. Promote to production from the deploy dashboard once staging looks right.
