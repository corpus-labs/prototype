---
title: Accessibility review
description: The checklist every new template passes before it ships.
---

Run this on every new page template before it ships.

- Every image has alt text, or is marked decorative.
- Headings go in order without skipping a level.
- Everything works with a keyboard alone.
- Text meets WCAG 2.2 AA contrast in both themes.
- Forms say what went wrong and how to fix it.

## Tools

Use the browser’s accessibility tree and a screen reader. Automated checks catch only part of what people run into.
